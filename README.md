## 概要
Next.jsとNuxt.jsの比較研究  
本研究では、NextjsとNuxtjsを用いて同一のWebサイトを実装し、両フレームワークの開発効率、学習曲線を比較します。

## バージョン構成
以下のバージョンで比較・検証しています。

Next.js 16.2.6  
Nuxt.js 4.4.2  
Mysql 8.4
